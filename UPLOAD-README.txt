가평에서 살아볼까 웹사이트 서버 업로드 안내

1. 이 폴더 안의 index.html, 404.html, assets 폴더 전체를 호스팅 서버의 웹 문서 루트(public_html, www, htdocs 등)에 업로드합니다.
2. index.html은 반드시 웹 문서 루트에 있어야 합니다.
3. assets 폴더는 index.html과 같은 위치에 있어야 합니다.
4. 기존 index.html이 있다면 백업 후 교체합니다.
5. 업로드 후 도메인에서 Ctrl+F5로 새로고침합니다.

주의: src/main.tsx는 개발용 원본 파일이므로 일반 서버에 올릴 필요가 없습니다.
