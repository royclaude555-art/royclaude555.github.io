# 가평에서 살아볼까 | 삶의 조건을 확인하는 72시간

기존 `gapyeong-living-docu` 프로젝트와 분리된 상세페이지형 홈페이지입니다. 돈을 버는 방법보다 주거·관계·속도·건강·일상의 조건을 직접 확인하고 자신의 다음 삶을 선택한다는 메시지를 중심으로 구성했습니다.

## 포함된 흐름

첫 화면에서 질문을 던진 뒤, 삶의 조건 5가지, 세 참여자 프로필, 3일·7일·한 달 체류 방식, 주거 선택 카드, 문의 신청 폼으로 이어지는 긴 상세페이지 구조입니다. 참여자 카드를 누르면 72시간 검증 점수와 생활비·주거·일 정보가 포함된 프로필 모달이 열립니다. 체류 방식과 주거 카드는 클릭해 선택 상태를 바꿀 수 있고, 신청 폼은 제출 후 완료 상태를 보여줍니다.

## 로컬 실행

Node.js가 설치된 환경에서 프로젝트 폴더로 이동한 뒤 `pnpm install`을 실행하고 `pnpm dev`를 실행합니다. 기본 개발 서버는 Vite 포트 5173을 사용합니다.

프로덕션 확인은 `pnpm build`로 실행합니다. 생성된 `dist` 폴더는 Vercel, Netlify, 닷네임코리아 일반 웹호스팅 등에 올릴 수 있는 정적 배포 결과물입니다. 일반 호스팅에서는 `dist` 안의 파일을 웹 루트에 업로드하면 됩니다.

## 이미지 교체

`public/assets` 안의 `hero.webp`, `person-a.webp`, `person-b.webp`, `person-c.webp`, `calculation.webp`를 같은 파일명으로 교체하면 코드 수정 없이 이미지가 바뀝니다. 현재 이미지는 기존 가평 프로젝트에서 사용하던 시각 자산을 새 버전으로 재사용한 것입니다.

## 주의

현재 문의 폼은 프런트엔드 확인용 성공 상태를 보여주는 단계입니다. 실제 접수 저장·메일 알림·DB 연동은 기존 가평 프로젝트의 신청 API와 연결할 때 추가하면 됩니다. 주거 가격과 체류 정보는 실제 답사·운영 데이터로 업데이트해야 합니다.
